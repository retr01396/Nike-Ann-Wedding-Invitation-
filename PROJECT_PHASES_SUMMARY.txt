1. PROJECT VISION & ARCHITECTURE OVERVIEW
================================================================================
The project transforms a bespoke luxury stationery wedding invitation into a
single continuous, cinematic, scroll-driven web experience. Instead of a
generic card-based website, the entire application flows seamlessly like an
unfolding physical invitation suite:

   [Hero Monogram & 3D Envelope]
              ↓ (Seal Break & Card Emergence)
   [Two Souls: Our Story Timeline]
              ↓ (Drawn Gold Hairline Chronology)
   [The Celebration: Events & Dossiers]
              ↓ (Holy Matrimony, Groom's House, Reception)
   [Travel & Cartography: Getting to Thrissur]
              ↓ (Airports, Railway, Road, Interactive Maps)
   [Kindly RSVP & Hospitality Flow]
              ↓ (Segmented Controls, In-Flow Stay Expansion, Wax Seal Confirmation)
   [Supabase Backend & Admin Operations Console]
                (Row-Level Security, Real-Time KPIs, Filters, CSV Export)

Central Configuration Rule:
All couple names, dates, placeholder labels, event timings, venues, travel
hubs, and RSVP copy are centralized in `src/config/wedding.ts`. No copy or
coordinates are hardcoded across UI components.

2. PHASE 1: MONOGRAM & HERO ENVELOPE EXPERIENCE
================================================================================
Phase 1 establishes the first impression of the wedding website with a tactile,
editorial stationery opening.

Key Features & Implementations:
- Monogram Pre-loader & Reveal:
  Embossed circular gold monogram medallion featuring the interlocked "N/A"
  insignia with subtle radial lighting and floral filigree.
- 3D Interactive Envelope:
  A custom CSS/GSAP 3D envelope structure with realistic flap folding, deep wine
  textured velvet shading, and fine gold edge borders.
- Wax Seal Breaking Interaction:
  Clicking or tapping the gold wax seal initiates a realistic opening sequence:
  the seal breaks, the top flap unfolds upward in 3D perspective, and the
  inner invitation card smoothly emerges out of the envelope.
- Letter Emergence & Scroll Cue:
  The formal invitation letter card emerges with formal typography:
  "The Wedding of Nike & Ann", ceremony date, and invitation text.
  A subtle pulsing gold arrow prompts the user to scroll into the journey.
- Audio / Ambient Atmosphere:
  Optional ambient sound triggers accompanied by smooth visual transitions.

================================================================================
Phase 4 provides comprehensive transportation, accommodation, and cartographic

Key Features & Implementations:

  Built strictly around configurable location data in `src/config/wedding.ts`.

  * By Air: Cochin International Airport (COK - ~55 km) and Calicut (CCJ - ~85 km)
  * By Rail: Thrissur Railway Station (TSR - central connectivity)
  * By Road: National Highway 544 transit guidelines and local cab advice
- Interactive Stylized Cartography:
  Dark-romantic cartographic canvas featuring deep burgundy terrain, gold route
  lines, destination pins with gold halos, and zoom/pan controls.
- Directions & Route Launchers:
  "Get Directions" buttons that open map navigation dynamically based on
  configured coordinates.
- Guest Assistance & Concierge:
  Dedicated hospitality note with travel desk contact placeholders for guests
  requiring airport pickup or assistance.

7. PHASE 6: SUPABASE BACKEND, RSVP DATABASE & ADMIN DASHBOARD
================================================================================
Phase 6 adds the complete production database infrastructure, Row-Level Security,
administrative authentication, and an executive operations dashboard.

Key Features & Implementations:
A. Database Schema (`supabase/migrations/001_create_rsvps.sql`):
   - `public.admin_users`: Explicit authorization table mapping `user_id` to
     roles ('admin', 'superadmin').
   - `public.rsvps`: Production table matching Phase 5 `RSVPSubmission`:
     id (uuid), full_name, attendance, guest_count, dietary_preference,
     dietary_other, needs_accommodation, phone, arrival_date, departure_date,
     rooms_needed, needs_transport, notes, created_at, updated_at.
   - Database Constraints & Security Hardening:
     * `valid_date_order`: departure_date >= arrival_date
     * `valid_accommodation_fields`: phone, arrival_date, departure_date required
       if needs_accommodation is true
     * `is_admin()` Security Definer hardened with `SET search_path = ''` to prevent
       search-path injection attacks.
     * Default table permissions revoked from `PUBLIC`.

B. Strict Row Level Security (RLS):
   - Anonymous (`anon` role): Allowed ONLY to `INSERT` into `public.rsvps`.
     Cannot read, list, update, or delete any RSVP records.
   - Authenticated Admins: Allowed `SELECT`, `UPDATE`, `DELETE` on `public.rsvps`
     strictly if `public.is_admin()` verifies the user's UUID is in `admin_users`.
   - Authenticated Non-Admins: Blocked from all RSVP data (returns 403 Forbidden).
   - Zero Privileged Service Keys: The application uses authenticated user tokens
     exclusively; no `SUPABASE_SECRET_KEY` or service-role key is required.

C. API Endpoints:
   - `POST /api/rsvp`: Public submission handler with IP rate-limiting (max 10/min),
     strict runtime shape & length validation, and unconfigured fallback.
   - `GET /api/rsvp`: Returns 405 Method Not Allowed (zero guest enumeration).
   - `GET /api/admin/rsvps`: Protected admin listing endpoint.
   - `GET /api/admin/rsvps/[id]`: Protected admin single-record inspector.
   - `PATCH /api/admin/rsvps/[id]`: Protected admin updater with strict constraint validation.
   - `DELETE /api/admin/rsvps/[id]`: Protected admin record deletion.
   - `POST /api/auth/logout`: Server-side cookie cleanup.

D. Admin Operations Console (`/admin`):
   - Executive KPI Metrics:
     * Total Responses
     * Attending Guests (strictly excludes declined entries)
     * Declined Responses
     * Rooms Needed
     * Airport Transits Needed
   - Debounced Search: 300ms live text filter for guest names.
   - Multi-Filter Matrix: Attendance, Lodging, Dietary, Transit, and Sorting.
   - Responsive Dual-Mode Presentation:
     * Desktop (>= 768px): Data table with gold hairlines and action menus.
     * Mobile (< 768px): Luxury stacked cards with zero horizontal overflow.
   - Detailed Dossier View (`/admin/rsvps/[id]`): Complete guest inspection.
   - Inline Edit Modal (`EditRSVPModal.tsx`): Safe updates to guest records.
   - Two-Step Deletion Modal (`DeleteConfirmModal.tsx`): Accidental loss prevention.
   - RFC-4180 Compliant CSV Export: Escapes quotes/commas, downloads date-stamped file.

E. Admin Login Portal (`/admin/login`):
   - Clean, full-screen dark burgundy sign-in interface.
   - Top dashboard navigation is completely hidden from the login screen via
     Route Group isolation (`src/app/admin/(dashboard)/layout.tsx`).
   - Displays clear setup instructions when Supabase environment variables are missing.

9. SETUP & HANDOVER INSTRUCTIONS
================================================================================
To connect the application to your live Supabase project:

1. Create a Supabase Project:
   - Visit https://supabase.com and create a project.

2. Run Database Migration:
   - Copy the SQL from `supabase/migrations/001_create_rsvps.sql`.
   - Paste and execute it in your Supabase Project's SQL Editor.

3. Configure Environment Variables:
   - Create a `.env.local` file in the root directory:
     ```
     NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
     NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-anon-key
     ```

4. Authorize Your First Administrator:
   - In the Supabase Dashboard, go to Authentication -> Users and invite or add
     your admin email (e.g., admin@example.com).
   - In the SQL Editor, insert that user's UUID into `public.admin_users`:
     ```sql
     INSERT INTO public.admin_users (user_id, role)
     VALUES ('your-user-uuid-here', 'superadmin');
     ```

5. Launch & Manage:
   - Run `npm run dev` or `npm run build && npm run start`.
   - Visit `/admin/login` to sign in to the operations console.
   - Consult `docs/SUPABASE_SETUP.md` for complete technical documentation.
